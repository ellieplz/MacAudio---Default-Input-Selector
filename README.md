macOS app that lives in your Menu Bar and allows you to change default audio output AND input without need to use System Settings or Audio MIDI Setup.

What's inclued (so far!):
- Ability to select default audio input device
- Ability to select default audio output device
- Ability to select default webcam (experimental! macOS does not support this natively)
- Option to "latch" to audio devices and prevent it from automatically changing
- Option to launch on login
- Option to hide dock app
